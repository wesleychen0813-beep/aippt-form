# AIPPT 需求录入器

逐页精细控制 PPT 需求的可视化录入工具。填完「保存」得到带数据的 HTML，交回给 AI 生成 PPT。

## 功能

- **全局设置**：参考 Skill、视觉风格（30 种）、叙事结构（30 种）、三色色盘、整份视觉要求
- **逐页录入**：页码 / 标题 / 内容（第一行写结论）/ 视觉意图 / 处理方式标签 / 参考截图（⌘V 粘贴）
- **保存写回**：数据存在 `SPEC-DATA` JSON 块里，AI 直接读取

## 用法

1. 打开页面，填「全局设置」（参考 Skill、风格、叙事、配色）
2. 逐页填「这页内容」和「这页视觉」，可贴截图
3. 点右上角「保存」→ 下载「已填写」的 HTML 文件（浏览器安全限制，不能覆盖原文件）
4. 把文件发给 AI，AI 读 `SPEC-DATA` 生成 PPT

## 出处

- 30 视觉风格 + 30 叙事结构清单参考 AiPPT RedSkill（`aippt-official-brief-generator`）
